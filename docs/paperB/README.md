# Paper B — the manuscript (PRL draft)

The PRL attempt: *effective line redistribution in kilonova ejecta —
transport-relevant structure is frequency-local*. Gates G1–G3 are
preregistered, run and frozen (`paperB-g2-freeze`, `paperB-g3-freeze`).
The submission map is [`paperB/plan.md`](../../paperB/plan.md) (the PI's,
2026-10-05): **G2 is the discovery** (observable fidelity is not
microscopic fidelity; frequency locality is the structure the radiation
samples), G1 the set-up, G3 the generality proof. The Letter is structured
for APS: a core of about 2,250 words plus three full-width figures (the
budget is 3,750 with figure equivalents; `make check` prints the count),
and an End Matter carrying the gate tables, the amendments made during the
runs, the transport's validation (so the Letter is self-contained without
the companion methods paper), and data availability. Built with `revtex4-2`
(aps, prl, twocolumn) since 2026-10-05; `docs/paperB/cover_letter.md` is the
cover-letter draft.

The references added for the literature positioning (Hummer 1962; Benner
et al. 2015; Zahm, Billaud-Friess & Nouy 2017; Peng et al. 2020) carry the
DOIs the PI verified on 2026-10-05; Zahm et al.'s title and page range are
still to be confirmed against the DOI.

**Every number printed is a macro** generated by `latex_tables.py` from
`paperB/FROZEN.json`, which `paperB/freeze.py` builds as a pure function of
the committed gate records (G1's verdict, the R2M robustness verdict, the
exit-table audit, G2's verdict, G3's verdict), each hashed in the record. Nothing is typed
into the prose; `check_structure.py` fails on a literal result number, an
undefined macro, a missing figure, or a table fragment that is not the
regeneration of the frozen record. Tests: `tests/test_paperB_freeze.py`.

## The argument

1. **Scalar insufficiency** — a single ε, optimally tuned, cannot
   reproduce energy-conserving fluorescence (G1, F67).
2. **Local compression** — a handful of contiguous frequency groups can,
   and the operator follows the fluorescence physics it is built from
   (G1/R2M, F67–F68).
3. **Mechanism** — global representations that reproduce the microscopic
   events better reproduce the radiation worse; the success is
   frequency-local transport structure, not generic dimensional reduction
   (G2, F69).
4. **Generality** — the operator is compact everywhere but universal
   nowhere: its parameters, and for Ce II its required resolution, depend
   on the state; a table over single coordinates captures the dependence,
   a coupled trajectory does not; the realistic mixture stays as compact
   as any single ion while per-species operators do not compose (G3, F70).

The claim is deliberately *not* "millions of transitions collapse to a few
numbers". The compressibility is two-level: P(ν_out | ν_in) = P(j | i)
P(ν_out | i, j), the first factor extremely coarse, the second still
needing a sparse but appreciable set of real exit lines (L\* = 0.358 on
Ce II, 0.113 on Nd II).
