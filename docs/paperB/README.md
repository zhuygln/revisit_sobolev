## The argument

1. **Scalar insufficiency** — a single ε, optimally tuned, cannot
   reproduce energy-conserving fluorescence (G1, F67).
2. **Local compression** — a handful of contiguous frequency groups can,
   and the operator follows the fluorescence physics it is built from
   (G1/R2M, F67–F68).
3. **Mechanism** — at 32 archetypes the global representation reproduces
   the microscopic events better and the radiation worse; the
   representation the light accepts keeps contiguous frequencies together.
   Whether adjacency itself, rather than rank or parameter count, is what
   it exploits is the preregistered ablation G2R (not yet run); the words
   "locality rather than low rank" are not used (G2, F69).
4. **Generality** — the operator is compact everywhere but universal
   nowhere: its parameters, and for Ce II its required resolution, depend
   on the state; a table over single coordinates captures the dependence,
   a coupled trajectory does not; the realistic mixture stays as compact
   as any single ion while per-species operators do not compose (G3, F70).

The claim is deliberately *not* "millions of transitions collapse to a few
numbers". The compressibility is two-level, and the reduced model as
implemented is P_red(ν_out | ν_in) ≈ P(j | i) P(ν_out | j) with i = i(ν_in):
the first factor extremely coarse, and once the output group is chosen the
exit line is drawn from that group's table, which no longer remembers the
input group; the second factor still needs a sparse but appreciable set of
real exit lines (L\* = 0.358 on Ce II, 0.113 on Nd II).
